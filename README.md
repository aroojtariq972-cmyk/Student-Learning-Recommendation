# Student-Learning-Recommendation
A Machine Learning project that recommends personalized learning resources based on student performance, learning preferences, and study habits.
## Overview
This project uses Machine Learning to recommend personalized learning strategies and resources based on student information such as academic performance, study hours, learning preferences, and assessment results.

## Features
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning Model
- Model Evaluation
- Confusion Matrix
- Prediction System
